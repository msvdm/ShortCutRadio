ShortCutRadio is a radio and music player that lives in a corner of the
screen, over games too, and that you drive with the keyboard.

**Which file to take**

- **Windows 10 or 11:** `ShortCutRadio-*-windows-x64-setup.exe` installs it
  with a Start menu entry, no administrator rights needed. Or take the
  `.zip` for a portable folder that keeps its settings inside it.
- **Linux (X11: Linux Mint, Ubuntu 22.04 or newer and similar):**
  `shortcutradio_*_amd64.deb`, double-click to install. Or take the
  `.tar.gz` for a portable folder that keeps its settings inside it.

The Windows installer isn't signed yet, so Windows may warn that it comes
from an unknown publisher: choose **More info**, then **Run anyway**.

How to use it is in the [README](https://github.com/msvdm/ShortCutRadio#readme).
